# iPhone 网页 App 安装指南

朝露酒笺当前优先采用 **PWA（渐进式网页应用）** 方案支持 iPhone。它不需要从 GitHub 下载 IPA，也不需要通过 App Store 安装；用户可直接把在线版添加到 iPhone 主屏幕。

## 安装地址

在线版：<https://zalan-dunk.github.io/Dawnsdew-WonderfulDrinking/>

## iPhone 安装步骤

1. 使用 **Safari** 打开上面的在线版地址。
2. 点击 Safari 底部或顶部工具栏的“分享”按钮（方框上方带向上箭头）。
3. 在分享菜单中选择“添加到主屏幕”。
4. 确认名称为“朝露酒笺”，点击右上角“添加”。
5. 返回桌面，点击朝露酒笺图标即可全屏启动。

如果链接最初是在微信、QQ、邮件或其他应用中打开，请先选择“在 Safari 中打开”。这些应用的内置浏览器通常不会显示完整的主屏幕安装入口。

## 离线与数据说明

- 首次安装和首次完整载入需要联网。
- 完整载入一次后，应用外壳、内置配方、样式与图标会缓存到设备，可在断网时继续打开。
- 酒柜、收藏、今夜酒单、自定义配方和设置继续保存在当前设备的浏览器本地空间中。
- 删除主屏幕图标通常不会立即清除 Safari 网站数据，但清理 Safari 历史记录与网站数据可能导致本地数据丢失。
- 建议定期在“数据管理”页面导出 JSON 备份。

## 更新方式

在线版更新后，重新联网打开应用即可在后台获取新版本资源。若长时间未更新，可完全关闭朝露酒笺后重新打开；仍未生效时，可在 Safari 中重新访问在线地址。

## 当前限制

- PWA 不是 App Store 原生应用，不通过 GitHub Release 分发 IPA。
- iOS 不支持像 Android APK 那样让普通用户直接安装任意未签名安装包。
- PWA 的本地数据与 Safari 网站数据关联，暂不支持账号或多设备自动同步。
- 系统级能力受 Safari/PWA 限制；后续若需要推送通知、原生分享增强或 App Store 上架，可再建立 Capacitor iOS 工程并通过 TestFlight 测试。
